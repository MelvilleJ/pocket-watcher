# antislop audit 001 (2026-11-21)

Scope: web dashboard (`app/`, `components/`, `app/globals.css`) and Expo app (`mobile/src`, `mobile/app.json`).
Mode: AFTER. Nothing has been changed. Pick numbers to fix; unlisted numbers stay untouched.

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.
Tags: **[W]** web, **[M]** mobile, **[W+M]** both (mobile `constants/theme.ts` mirrors `globals.css`, so token fixes land in both).
Contrast ratios are WCAG values computed from the token hex values. Nothing was clicked through on a device or logged-in browser yet (R-35).

## HIGH

1. **[W+M] R-37 No design direction on file.** There is no `DESIGN.md`. The token system is coherent (pink `#ff5c8d` + aqua, blue-grey neutrals, Geist, soft radii) but no reason is recorded for any of it. Fix: write a short `DESIGN.md` (identity, palette, type, dials) so later fixes have something to hold to.
2. **[W+M] R-25 `muted-soft` text fails contrast.** Light `#98a1b8` is 2.58:1 on white; dark is 3.8-3.96:1. Used for form labels, table/day headers, section subtitles, sidebar group labels, placeholders, chart axis text (`globals.css:777,1203,1338`, `dashboard-nav.tsx:105,114,128`, `mobile/src/components/ui/text.tsx:192`, `ui/layout.tsx:199`, `theme.ts:15,18`). Also `text-zinc-400` "Cancelled"/"Signed out" (2.56:1). Fix: light about `#6b7489`, dark about `#8d95ab`; use `muted` for labels.
3. **[W+M] R-25 Accent and status colors used as small text.** Hero stat values in `--page-accent` (amber 1.88:1, aqua 2.16:1, pink 2.93:1), "Unpaid" warning about 2:1, fee chip 2.4-2.65:1, good-green text 3.43:1, primary links "Log in"/"Create an account" and auth eyebrow 2.93:1. Fix: add `*-text` variants at 4.5:1; keep bright hues for fills and icons.
4. **[W+M] R-25 White labels on colored buttons.** Primary gradient 2.93:1, "Lock budget"/"Log income" good 3.43:1 (1.96:1 dark), "Log expense"/"Log out" critical 3.91:1 (2.77:1 dark). `budget/page.tsx:83`, `globals.css:1279-1287`, `mobile/src/components/ui/controls.tsx:60`. Fix: deeper fills for white text, or dark text on the lighter dark-mode fills.
5. **[W+M] R-34 Dark mode reuses light `primary-soft` (`#ffe5f0`) and `primary-deep`.** Active nav pill and selected sheet options become bright pastel-pink blocks on near-black, text 2.47-3.73:1 (`globals.css:55,352-361`, `theme.ts:33`, `app-header.tsx:99`, `controls.tsx:305`). Fix: dark tint (about 16-18% primary into surface) and a lighter dark `primary-deep`.
6. **[W] R-34 Login and signup break in dark mode.** Hard-coded `text-slate-700` labels (1.79:1 on the dark card), `bg-rose-50` error box, `text-slate-500` footer (`app/login/page.tsx:20-35`, `app/signup/page.tsx:20-45`). Fix: swap to tokens.
7. **[M] R-34 / R-27 ErrorBoundary is hard-coded dark, shows raw `error.stack`, offers no recovery** (`mobile/src/components/error-boundary.tsx:21-40`). Fix: tokens, plain message, "Try again" reset, stack only under `__DEV__`.
8. **[W+M] R-25 Chart colors vanish.** Off-palette hard-coded blue ramp: lightest bar 1.15-1.32:1 on light, darkest 1.31-1.55:1 on dark (`category-breakdown-chart.tsx:23-31`, `mobile/src/components/charts.tsx:137`). Avalanche/snowball lines are 1.24-1.68:1 apart and differ by color only (`debt-roadmap-planner.tsx:83-84`, `roadmap-area-chart.tsx:60-62`, `mobile debts.tsx:212-213`). Money-flow stacked segments 1.06-1.28:1 apart. Fix: ramp from a brand hue clamped to 3:1 per theme, distinct series hues or a dashed line, surface stroke between segments.
9. **[W+M] R-39 Fields without a visible label or accessible name.** Web: debt, goal, debt-payment, goal-contribution and subscription forms are placeholder-only; budget planned input has no name (`budget-line-row.tsx:72`); settings currency uses a `<span>`. Mobile: `Field` never passes its label to `TextField`, so VoiceOver reads "0.00, text field" (`controls.tsx:152-180`); same for budget inputs, switches, roadmap slider; depo name and server URL are placeholder-only. Fix: web `.txn-field` + `.txn-label` pattern everywhere; mobile `Field` passes `accessibilityLabel`.
10. **[M] R-39 Almost no roles or states.** One `accessibilityRole` in the whole app. `Button` has no role or disabled/busy state, nav pills no tab role or selected state, `Segmented` no selected state, calendar and history rows no expanded state, depo swatches announced as hex codes, charts have no summary. Fix: role + label + state on every Pressable; chart `accessibilityLabel` stating its answer.
11. **[W] R-39 Missing affordances and page semantics.** Main action buttons (`zinc-900` submits, Save, Lock/Unlock, `.depo-submit`, `.txn-submit`) have no hover/active state; checkbox labels lack `cursor: pointer`; nav links lack `aria-current="page"`; every page shares the `<title>` "Pocket Watcher"; auth renders an h2 before the h1 (`auth-shell.tsx:51,78`); disabled stepper is a `<span aria-label>` (`year-picker.tsx:45`). Fix: base hover/active styles, `label:has(input)` cursor rule, `aria-current`, per-route `metadata.title`, headline as `<p>`.
12. **[W] R-39 Calendar month cards are buttons wrapping headings, lists and 31 day spans** (`month-calendar-viewer.tsx:115-191`). Day amounts live only in a `title` tooltip, unreadable by touch or keyboard; hover expands to `row-span-2` and reflows the grid. Fix: card as `<div>` with a separate Compare button, visible/focusable day detail, no reflow.
13. **[W] R-32 Weak input focus ring and no skip link.** `outline:none` (`globals.css:162`) replaced by a 1px pink border (2.93:1) and faint halo; keyboard users tab through logo + 9 nav links first. Fix: 2px `:focus-visible` ring at 3:1+, "Skip to content" link.
14. **[W+M] R-03 Tap targets under 44px.** Web: mobile nav links 34, logout 32, steppers 30, txn filters about 24, Mark paid/Delete/Edit/Remove text links about 16, swatches 28. 15. **[M] R-03 Tab-screen forms do not avoid the keyboard.** `Screen` ScrollView (`ui/layout.tsx:68`) has no keyboard handling; decimal pad covers lower budget lines and debt/goal/settings forms. Fix: `automaticallyAdjustKeyboardInsets` or `KeyboardAvoidingView`.
16. **[M] R-03 Fixed heights clip text at large font scale.** `Button`, nav pills, `Segmented`, calendar day cells (30x24); no `maxFontSizeMultiplier` anywhere. Fix: `minHeight` + padding; cap multiplier on dense cells.
17. **[W] R-27 No loading or error routes.** No `loading.tsx`, `error.tsx` or `not-found.tsx` under `app/`; failures show the default Next page and `budget/page.tsx:41` returns `null` (blank page). Fix: `app/dashboard/loading.tsx`, `error.tsx` with `reset()` retry, real empty/redirect for budget.
18. **[W+M] R-27 Budget autosave hides failures.** Web `saveNow` swallows errors (`budget-line-row.tsx:39-46`), Save button gives no feedback (`save-all-button.tsx:7`); subscription toggle stays checked after a failed save on both (`subscription-budget-line-row.tsx:35-37`, `mobile budget.tsx:338-343`). Fix: saving/saved/error status, roll toggle back on failure.
19. **[M] R-27 Sync failures are silent outside Settings.** Non-auth errors and server-rejected records are dropped in `useLocalData` (`mobile/src/lib/local.ts:27-29`). Fix: expose status/rejections and show a "N changes not synced, Retry" notice on affected screens.
20. **[M] R-27 Logout can wipe unsynced data without warning.** `pushSync().catch(() => {})` then `clearLocalData()` (`auth-context.tsx:116-120`); header confirm does not mention it. Fix: check `hasUnsyncedChanges()`, warn with the count, one shared confirm.
21. **[M] R-27 Errors misdiagnose the cause and stale data is undated.** Every failure (500s included) says "Couldn't reach the server. Showing the last saved figures." even with no cache (`remote.ts:55`); `fetchedAt` never shown; no-data fallbacks have no Retry. Fix: distinguish offline vs server error, "Last updated ...", Retry button.
22. **[W+M] R-27 Empty states that mislead or stop short.** Mobile transactions says "Nothing logged yet" while a filter is active (`transactions.tsx:137-140`); session revoke swallows errors (`settings.tsx:101`). Web: "No debts/goals/subscriptions/activity logged yet." with no next step; budget income/expense tables have no empty row; money-flow chart draws empty axes for new users. Fix: name cause + next action, as the web transactions empty state already does.
23. **[W+M] R-17 Numbers on screen that are wrong or have no data behind them.** Web transactions "In/Out this month" computed from the filtered, 200-capped list (filter to "In" and Out reads 0.00) (`transactions/page.tsx:73-85`). 24. **[M] R-26 Scan is a dead feature.** Photo is captured then discarded ("coming in a future update"), permission text claims receipt scanning, `RECORD_AUDIO` requested but unused, "Grant camera access" does nothing when permanently denied (`scan.tsx:36-51`, `app.json:22-24`).
